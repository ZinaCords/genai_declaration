# genai_declaration
This generator helps you disclose any AI use, critical engagement with AI, and accountability for the accuracy and quality of your submission. Use this output to add to your assessment submission.

Open dist/index.html in a modern browser. All website source is editable: index.html (content), styles.css (appearance), app.js (behaviour and exact official checklist).

No installation or build is required. Host the contents of dist on any static web host for student access. The Sites preview is private to its owner; use your institution's hosting for an account-free student version.

The seven checklist statements are reproduced from the included original document. Evaluate/Decide/Apply prompts and conditional N/A handling are added learning guidance. No personal data is transmitted or stored by the application. Refreshing or closing the page clears entries. Export before closing.

Exports: copy, plain text, genuine .docx and print/PDF. Incomplete responses are exported with a DRAFT label. N/A is available only where the AI, group or DOI choices make a statement inapplicable. No-AI and AI-dependent statements cannot be confirmed in conflict with the declared use.

Check assessment-specific AI permissions before use. ECU-inspired colours do not imply ECU endorsement.
